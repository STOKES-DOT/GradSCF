# Rigid ethane torsion: MACE, free contraction and conventional bases

## Methods

Method: All-electron DF-RHF, def2-universal-jkfit. Cohort: `MACE-update-3351`. Exact settings, commands, hardware and original status fields remain in the imported source records. Numerical source files are copied without editing.

## Results

25 geometries, 0 to 120 degrees in 5-degree steps. Both free starts converged at every angle; 50 frozen bases were independently checked. Grid barriers: MACE 3.651135074 and free contraction 3.495155486 kcal/mol.

Archive status: `complete`. Exported geometry/state records: **50**.

## Interpretation boundary

Rigid scan, fixed exponents/core and 44 spherical AOs. It is not a relaxed torsional barrier or a global free-contraction limit.

## Files

- `structures/`: generated standard XYZ with Angstrom coordinates, charge and 2S in the comment. Missing state information is explicitly `None`, not assigned a guessed state.
- `artifacts/`: source data, coefficients, plots, scripts and protocol records with their original relative paths. Original-language notes are retained as source records.
- `../../structure-index.json`: coordinate/state provenance and aliases; `../../FILE_MANIFEST.json`: original paths and SHA256 checksums.
