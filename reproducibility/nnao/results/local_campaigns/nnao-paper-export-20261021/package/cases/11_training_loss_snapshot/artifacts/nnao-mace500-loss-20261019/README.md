## 数据和口径

- 500 个分子，固定指数训练 MACE；Adam batch_size=50，每 epoch 10 次参数更新。
- 学习率初值 1e-3，每 100 epoch 减半；保存点对应学习率 3.125e-5。
- 原训练使用 n001 / A100_80G×1 / 32 CPU / 512 GiB 申请内存，时限 72 小时。
- epoch 0–3 是旧的整集评估值；epoch 4 在流程切换后没有有效 loss，样本覆盖数为零。
- epoch 5–596 共 592 条完整记录是 `online_pre_update_mean`，每条覆盖全部 500 个样本。
  一个 epoch 汇总十个不同更新前参数时刻的 batch 能量，不等于该轮保存参数的整集重新评估能量。
- 所有在线记录都与 `restart-single-pass-99005.log` 的对应行逐条核对，容差 1e-12 Eh。
- 原来的 `best.npz` 与 `last_full_epoch.npz` 仍是 epoch 3 的旧整集检查点。
  单次评估流程不会自动更新它们，不能按文件名将它们当作 epoch 596 模型。

## 图的定义

`training-loss.png/.pdf` 左图是完整历史，区分旧整集值与在线均值，不连接缺失的 epoch 4。
右图显示 epoch 200 后的在线均值相对 epoch 200 的变化，单位 mEh/分子。
虚线是学习率减半的 epoch 边界。

`energy-log-trends.png/.pdf` 包含：

1. `G_k = E_k - min(E_5,...,E_596)`，纵轴对数。这是到本次最低在线记录的经验差距，
   不是到真正收敛能量、自由收缩极限或 CBS 的误差。epoch 596 的零差距不绘制，不添加人为 epsilon。
2. `D_k = |E_k-E_(k-1)|`，纵轴对数。蓝点表示能量降低，橙色空心三角表示回升；
   黑线为最近 20 个相邻 epoch 变化幅度的中位数。不跨记录口径、不跨缺失 epoch 求差。

不对负的绝对总能量取对数；不强制单调包络，也不拟合或宣称指数收敛。
