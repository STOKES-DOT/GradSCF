# NNAO-DZP-M：MACE 超参数调研与 50 体系实验提案

日期：2026-10-30；状态更新于 2026-10-31。**隐藏层 L=1/L=2 两组均已完成
300 epoch（Slurm 113006/113007）；其余扫参仍为提案。** 结果与逐分子对照见
[results-20261031/RESULTS.md](results-20261031/RESULTS.md)。实际执行配置见
[RUN_SPEC.md](RUN_SPEC.md) 和 `execution-plan.json`。以下保留完整调研和原始实验提案。

## 目标与控制变量

固定 NNAO-DZP-M 的壳层、primitive 数量、M 档指数池、内层收缩、几何和电子态，
比较 MACE 架构及优化设置对收敛全电子 DF-RHF 变分能量的影响。固定内层参数不等于
冻结芯电子。只有网络权重和由其给出的完整原始收缩系数参与优化；指数不更新。

目标为 50 个体系的等权平均收敛 RHF 总能量。可减去每个体系相同的初始化能量常数
来绘制下降曲线，该常数不改变梯度。这里不拟合 W1-F12/CCSD(T) 数据库标签，不将
能量/力监督学习的损失权重直接用于本目标。

沿用现有固定 primitive 积分缓存、含归一化的积分收缩、稳定 RHF 和标准 implicit
固定点求导，随后通过 MACE VJP 得到权重梯度。缓存必须属于相同 DZP-M 指数池和
积分近似，不能直接拿 SZP-L 的缓存替代。避免重新计算固定积分，不保存完整 ERI，
不计算指数 VJP。

## 核对过的真实基线

基线来自现有 DZP-M 的 update-1100 检查点配置，而不是演示模块的默认参数。
数值记录在 baseline.json。原检查点用于定义配置与指数池，不用其已训练权重启动
新的消融实验。其向量有 10,249,607 个参数，元数据声明可训练 10,249,601 个；这不
等于全部参数都影响收缩输出，上游未使用的能量 readout 需单独列出。

| 项目 | 当前值 | 解释与处理 |
|---|---|---|
| channels | 256 | 每个 irrep 的通道数；改变时同步改 hidden_irreps 的所有 multiplicity |
| hidden_irreps | 256x0e + 256x1o | 隐藏特征最大 L=1，不是 L=3 |
| max_ell | 3 | 边球谐展开阶数，与隐藏特征 L 分开控制 |
| correlation | 3 | 每层相关阶数；不把整个多层网络叫作仅四体模型 |
| num_interactions | 2 | 消息传递深度 |
| cutoff | 5.0 Å | 每层图截断；T*r 是感受野距离上界，不保证等价信息量 |
| num_bessel | 8 | 距离展开维数 |
| num_polynomial_cutoff | 6 | 当前检查点的 envelope 参数，首轮固定 |
| radial_MLP | [64,64,64] | 活跃的径向网络，确实影响消息与系数 |
| avg_num_neighbors | 11.5716401333 | 原 500 体系统计得到的实数归一化量，不是整数邻居上限 |
| coefficient head | (256+2) → 256 → 24 | SiLU 隐层，按元素输出；DZP-M reshape 为 6x4 并应用 mask |
| coefficient readout | 最后一层 0e | 不直接把非标量分量送给标量 MLP |
| zero_init | true | 输出 kernel 为零；trainable bias 为参考收缩，后续预测完整系数 |
| elements | 25 种 | 沿用同一元素表，不让元素表变化混入架构比较 |
| MLP_irreps / gate | 16x0e / SiLU | 指上游能量 readout，未直接进入当前收缩系数目标，不作为首轮容量变量 |

补充：当前 adapter 的 coefficient head 宽度与 channels 绑定；首轮宽度实验衡量
整个现有模型的容量变化，不声称只改变 backbone。若要独立改变 head_width，或拼接
各层 0e 特征，需要对 NNAO adapter 做小范围扩展，不修改 vendor。

zero_init=true 时，初始输出不依赖 backbone，所以第一轮骨干梯度为零是链式法则的
正常结果。输出 kernel 更新后骨干梯度可以出现，不能把初始一步当作梯度断图证据。

## 文献调研：直接证据与可迁移的设计

### 1. 原始 MACE：体阶、等变阶数与层数分别消融

[Batatia 等，NeurIPS 2022，§5.1、图 1/2](https://arxiv.org/html/2206.07697v2#S5.SS1)
比较 correlation=1/2/3、隐藏 L=0/1/2 和消息层数。其结果支持把相关阶数、角向
表示和深度分开研究，而不是只增大通道数。两层足够覆盖论文某些小分子，不是所有
化学体系或 NNAO 都只需要两层的定理。

### 2. 架构评估：深度与截断范围的交互

[Kovács 等，JCP 159, 044118 (2023)，§III、V](https://arxiv.org/html/2305.14247v2)
比较 2x3 Å、1x6 Å 和 2x5 Å 的模型，并讨论只看拟合误差不能代表动力学表现。
这说明深度实验要同时报告感受野。其“50 构型”案例来自分子构型/轨迹及能量、力
监督，与我们 50 个不同体系的 SCF 变分训练不是相同信息预算。

### 3. MACE-OFF：常用容量范围，但不是单变量消融

[MACE-OFF，表 2](https://arxiv.org/html/2312.15211v5#S2.SS3)
的 OFF23 small/medium/large 分别采用通道数 96/128/192、隐藏 L=0/1/2，
截断 4.5/5/5 Å。可据此选择合理测试范围，但不能从三套打包配置直接归因某一个
超参数。它们的监督能量/力训练方法也不直接定义我们的变分优化器。

### 4. 水溶液系统消融：等变性和宽度的收益依赖任务

[Hetzel、Stein，ChemPhysChem 27, e70385 (2026)](https://doi.org/10.1002/cphc.70385)
固定其他配置，系统改变通道数与 L=0/1，讨论精度、稳定性和效率。研究中宽度的
收益存在饱和，等变特征可比单纯增加通道更重要。这里只借鉴实验方法，不把该体系
的最优宽度当作 NNAO 最优宽度。

### 5. 电子结构目标的相关证据

[MACE-H，npj Computational Materials (2026)，补充 S2.1/S4/S6](https://arxiv.org/html/2508.15108v2)
也比较相关阶数、层数和隐藏角动量；某些更高阶设置改善域内预测，却恶化另一类
构型上的迁移。它支持研究这些交互，但 Hamiltonian 矩阵预测与不变的收缩系数输出
不是同一个目标，其参数值不能直接移植。

### 6. 效率研究与官方实现

[Beiersdorfer 等，MLST 7, 015016 (2026)](https://doi.org/10.1088/2632-2153/ae35cf)
把数值与计算效率放在一起评估。对 NNAO 尤其要分开记录 MACE 和 SCF/implicit
响应耗时；MLIP 文献的纯网络推理时间不是一次 NNAO 训练步时间。

[MACE 官方训练说明](https://mace-docs.readthedocs.io/en/latest/guide/training.html)
解释 hidden_irreps、correlation、cutoff 和优化更新预算。最终语义以本项目实际
vendored mace-jax 和 NNAO adapter 为准；已检查其单层 scalar collapse、径向 MLP
默认值和 node_feats 读取路径。

背景参考：[冻结迁移学习研究](https://doi.org/10.1038/s41524-025-01727-x)。本提案主实验
从头训练，不把预训练模型暴露过的额外数据混进容量比较。

## 50 个备选体系

proposed50.json 已从原有 500 结构池选出 50 个不同的几何距离签名：

- 全部中性、spin=0，电子数一致且为偶数；最大 28 原子，中位数 8.5。
- 覆盖现有 25 元素。保留 6 个原子/双原子对照，用于径向和元素偏置行为。
- 至少 20 个 8 原子以上的 HCNOF 分子，给角向、多体与深度实验提供信息。
- 其他样本覆盖较重主族、卤素和非共价环境；同一来源子集最多五个。
- 50 个全部参与训练，本轮不切分 validation/test；结论定位于拟合/优化能力。
- 单个稀有元素只有一条记录时，不作该元素泛化充分的结论。

这是备选输入，不是新的 SCF 收敛认证。原始清单的 readiness 布尔值是历史 metadata。
执行时资格由相同 DZP-M 缓存与训练第 0 轮的实际 SCF/稳定性/implicit 残差判断。
不另加差分梯度验证、CPU/GPU 对照或 CP/BSSE 计算。

## 训练协议

1. 重新初始化每个模型，seed=0。统一可训练参考 bias 与零输出 kernel，使初始
   物理收缩完全相同。Adam 状态独立，初猜/稳定化策略相同。
2. 有效 batch_size=50，micro_batch=1；一轮处理全部 50 个体系，平均梯度后更新
   一次。各体系在同一个 theta 上求值，日志是真正的固定参数均值，不是在线混合均值。
3. 提议优化器为 clip_by_global_norm(1) + Adam，beta=(0.9,0.999)，eps=1e-8；
   初始 LR=1e-3，按 1000 个 optimizer updates 的 cosine 日程降至 1e-5。
   初筛仅跑同一日程的前 300 轮，不重新缩短日程；后续可从同状态继续到 1000。
4. 这个 cosine 日程是新实验提议，不冒充旧配置：旧 500 体系任务每轮十次更新，
   每 100 轮减半，相当于每 1000 次更新减半。不能把其 epoch 计数直接搬到新 batch。
5. 主消融统一 300 次更新，不因各自不同的早停点决定容量排名。旧的十轮累计变化
   小于 0.1 mEh 可保留为收敛标记，不用它提前结束某些架构造成训练预算不等。
6. 首轮 12 组只用 seed=0 筛选。第二阶段建议选原架构加两种代表性候选，补 seed=1/2，
   以三个 seed 到统一 1000 次更新的结果报告均值、标准差。第二阶段看首轮结果后决定。

SCF 固定为全电子 DF-RHF：energy 1e-12 Eh、density 1e-10、orbital residual 1e-9，
最多 150 cycles；沿用已验证的稳定化。implicit 容差 1e-8，max_iter=100，restart=40。
积分缓存采用同一 def2-universal-jkfit，指数固定，不触发 exponent VJP。

每体系每轮一次 value_and_grad，输出能量和标准 implicit 梯度；求解器内部迭代/
稳定化次数另记，不叠加外部重复评分。失败时保存候选和最后有效 checkpoint，停止
当前配置；不跳过失败分子，也不发布只对成功体系取平均的排名。

## 结果解释的边界

- MACE 包含按元素常数输出这一子空间：输出 kernel 为零、只调整 head_bias 即可。
  因此若 element-only 对照在同一目标上显著更低，优先检查优化、预算和数值分支，
  不能简单归咎于 MACE 的函数空间比常数模型小。
- 增宽、增加 L 或 correlation 后在同等预算和多 seed 下更低，支持相应参数对当前
  50 个体系的变分拟合有用；并不自动代表对未见分子的泛化更好。
- 固定指数池下，只有与同池同 AO 的自由收缩数值参照比较，才有助于区分网络差距
  和收缩结构的限制；未做该参照时不宣布已到基组表达极限。
- 更低的平均 RHF 总能量不保证反应能、相互作用能或 DOS 同步改善，本轮不以这些
  额外性质的数据库误差选择架构。

## 判断标准与第二轮可选变量

主看：完整 50 体系平均能量、相对共同初始化的下降（mEh/体系）、逐体系能量下降
的中位数/尾部，以及相对 element-only 对照的收益。报告 accepted updates、backbone
和 head 的梯度范数、SCF/implicit 收敛与稳定性、真实参数量、时间和峰内存。

DZ 收缩系数的符号、列置换及可逆列混合可以描述相同 AO 子空间。因此 raw coefficient
MSE 不作主要优劣指标；若比较径向空间，使用包含 Gaussian overlap 度量的子空间量。

第二轮按结果挑选 cutoff=3.5/5/6 Å、num_bessel=6/8/12、radial_MLP=[32,32]/[64,64,64]/
[128,128,128]。avg_num_neighbors 随 cutoff 从这 50 个结构重新统计，不能当整数容量扫。
可另扩展 head_width/深度和“各层 0e 拼接”输出头；后者只读不变标量，不直接拼非标量。
上游 MLP_irreps/gate 不作为系数预测容量变量。必要时针对明显优化异常的候选测试
LR=3e-4/1e-3/3e-3，避免把未优化充分误判为表示能力不足。

如需判断离自由收缩极限还有多远，再对十个代表性结构做同指数池、同 AO、同 core
约束的自由系数优化；这是额外诊断，不在首轮默认预算。多起点也只是 best-found
数值参照，不是严格全局下界。

## 资源与预算

每配置独占一张 A100/A800 80 GB，建议 16 CPU、128 GiB 主存；最多三个配置并行，
合计最多三卡、48 CPU，并与其他作业一起遵守既定资源预算。耗时对照优先同型号 GPU。
每个 run 独立进程，积分缓存共享，数据通过现有 host/mmap 路径调入；不新增跨分子
共享 JIT 研究。JIT 编译时间、缓存命中和热训练时间分开报告。

首轮包含第 0 轮共 12 x 301 x 50 = 180,600 次体系级 value_and_grad 调用。
不能按文献中的 MACE 推理毫秒数推算总时间。用 A0 正式训练最初十轮实测吞吐，
保留其进度，再给完整卡时估计；不为估时重跑一批 SCF。

预期输出：能量-更新步曲线、能量-墙钟时间曲线、能量-参数量/角动量/相关阶数对照、
50 个体系下降分布、梯度与收敛诊断表，以及完全可恢复的独立 checkpoints。

现阶段仅准备本说明、基线 JSON、12 组配置和 50 个备选结构，未启动训练。
