# 同池自由 SZ 与 DZ 对照

只增加价层第二个独立径向通道。固定原始 primitive 池、内层、极化壳层数量、几何、电子态及辅助基。
每结构 4 起点、每起点最多 500 步，使用与 SZ 一致的 Adam、收敛检查与隐式梯度。
当前最佳 SZ 被嵌入 DZ 初始空间；DZ 的起点条件不同，有限预算结果不等于两个空间的全局极限。
