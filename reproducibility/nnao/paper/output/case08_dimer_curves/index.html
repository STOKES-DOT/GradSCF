Case 08 dimer interaction curves

Twelve dimers. Each molecular inset shows the archived distance-scale-1.00 structure. Lines connect the measured eight- or ten-point scans without adding interpolated data.

12-page main-curve PDF | 12-page BSSE-corrected PDF | Main overview | Plotted data

The main curves use independently evaluated isolated monomers. For the BSSE-corrected curves, the basis predicted for the dimer is held fixed while each monomer is solved with and without ghost functions. The SCF orbitals are optimized in each calculation; only the basis parameters are fixed. These curves use the recorded counterpoise energies and a common dimer auxiliary metric.
