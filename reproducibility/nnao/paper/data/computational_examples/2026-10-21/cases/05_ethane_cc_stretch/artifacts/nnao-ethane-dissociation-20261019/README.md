## 径向定义和结果

选第一个碳 C0。价层 s、p 各由六个 primitive 收缩为一个径向通道，三个 p 分量共用径向部分。
`chi_lm=R_l(r)Y_lm`，`integral r^2|R_l|^2 dr=1`，
`<r>=integral r^3|R_l|^2 dr`。归一化和相位约定与扭转图一致；不额外将价层 s 与 core 正交化。
这是基函数形状，不能解释为占据原子轨道或电子密度的径向分布。

## 解释边界

这是用户确认的受限 RHF 压力测试，不是真实均裂解离曲线。
2.70–2.90 Å 的自由系数优化未收敛，附近能量有明显跳变；需独立检查 SCF 解分支及优化行为，
不能将两侧的已收敛端点默认视为同一连续物理解。未收敛点不用于报告自由变分极限。

分析包含 56 个 MACE 和 51 个通过终点的自由收缩的 C0 s/p，共 214 个径向函数。
最大归一化误差为 4.44e-16。该轮未新增有限差分，也未进行独立 PySCF 能量对照。
